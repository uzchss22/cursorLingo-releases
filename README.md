# CursorLingo

마우스 커서 주변의 글자를 인식해 번역해 주는 데스크탑 앱입니다. 단축키를 누르면 번역 결과가 커서 옆 팝업으로 표시됩니다.

## 기능

| 단축키 | 기능 |
|--------|------|
| `Alt + T` | 커서 위치의 글자를 번역합니다. 단어, 문장, 문단 중 번역 범위를 고를 수 있습니다. |
| `Alt + S` | 화면에서 영역을 드래그해 지정하면 그 안의 글자를 번역합니다. |
| `Alt + C` | 클립보드에 복사한 텍스트를 번역하고, 결과를 클립보드에 복사합니다. |
| `Alt + W` | 영역을 고정해 두면 그 안의 글자가 바뀔 때마다 자동으로 번역합니다. 게임 대사나 영상 자막에 쓸 수 있습니다. |
| `Alt + H` | 화면 위에 떠 있는 작은 번역 위젯(HUD)을 표시하거나 숨깁니다. |
| `Alt + Shift + H` | HUD의 클릭 통과를 켜거나 끕니다. |

macOS에서는 `Alt` 키가 `Option` 키입니다. 다른 프로그램이 같은 단축키를 쓰고 있으면 동작하지 않을 수 있습니다.

그 밖에 다음 기능이 있습니다.

- 번역 히스토리: 번역 기록을 계정에 저장하고, 즐겨찾기, 검색, 삭제를 지원합니다. 설정에서 저장을 끌 수 있습니다.
- 소리로 읽기(TTS): 번역 결과를 음성으로 읽습니다. 목소리, 속도, 볼륨을 고를 수 있고 번역 후 자동으로 읽게 할 수 있습니다.
- HUD: 투명도 조절, 위치 잠금, 게임 창 자동 추적, 메모와 타이머 기능이 있습니다.
- 번역 결과 자동 꺼짐: 켜 두면 팝업이 5초 뒤 닫힙니다.

## 번역 설정

번역 엔진은 Google과 Gemma(LLM) 중에서 고를 수 있습니다. Gemma를 선택하면 번역 스타일도 정할 수 있습니다.

| 스타일 | 설명 |
|--------|------|
| 기본 | 정확한 번역 |
| 친근한 | 친근하고 캐주얼한 어투 |
| 격식있는 | 공식적인 표현 |
| 간결한 | 핵심만 간략하게 |
| 학습모드 | 핵심 단어 설명 포함 |

인식할 수 있는 글자는 한국어, 일본어, 중국어(간체), 영어입니다. 번역 결과는 한국어, 영어, 일본어, 중국어(간체/번체), 프랑스어, 독일어, 스페인어, 러시아어로 받을 수 있습니다.

## 설치

### macOS

1. `.dmg`를 열고 `CursorLingo.app`을 응용 프로그램 폴더로 옮깁니다.
2. 처음 실행할 때 경고가 나오면 앱을 우클릭하고 열기를 선택하거나, 터미널에서 다음 명령을 실행합니다.
   ```bash
   xattr -dr com.apple.quarantine /Applications/CursorLingo.app
   ```
3. 시스템 설정의 개인정보 보호 및 보안에서 화면 녹화 권한을 CursorLingo에 허용합니다. 화면의 글자를 읽으려면 필요합니다.

### Windows

1. `.exe`를 실행해 설치합니다.
2. SmartScreen 경고가 나오면 추가 정보를 누른 뒤 실행을 선택합니다.

### Linux

```bash
chmod +x CursorLingo-x.x.x-linux.AppImage
./CursorLingo-x.x.x-linux.AppImage
```

실행되지 않으면 `libfuse2`를 설치해 보세요.

## 사용 방법

1. 앱을 실행하고 회원가입 후 로그인합니다. 로그인해야 번역할 수 있습니다.
2. 설정 화면에서 번역 엔진, 번역 범위, 인식할 언어와 번역 결과 언어를 고릅니다.
3. 번역할 글자 위에 마우스를 올리고 `Alt + T`를 누릅니다.

창을 닫아도 앱은 백그라운드에서 실행되며 단축키는 계속 동작합니다.

글자가 잘 인식되지 않으면 설정의 인식 언어가 화면의 글자와 맞는지 확인하세요. 번역이 되지 않으면 로그인 상태와 인터넷 연결을 확인하세요.
